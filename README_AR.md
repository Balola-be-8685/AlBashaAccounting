# الباشا للمنظفات – النظام المحاسبي لأندرويد

هذه نسخة تطويرية (3.0) من مشروع Android Studio. التطبيق يعمل بواجهة عربية RTL داخل تطبيق أندرويد مستقل (WebView)، ويحفظ البيانات محلياً على الجهاز.

## الوظائف الموجودة في هذه النسخة
- فصل الحركات المالية إلى حساب المصنع وحساب المحل، مع ملخص موحّد.
- تسجيل المبيعات والمصروفات والمشتريات والتحصيلات وسداد الموردين ورأس المال.
- تسجيل تشغيلات الإنتاج وحساب تكلفة الدفعة وتكلفة اللتر، مع إضافة كمية الإنتاج للمخزون التام.
- إدارة أصناف المخزون (منتج تام، خامات، عبوات) وحركات الإضافة والصرف وحد التنبيه.
- تسجيل العملاء والموردين والأرصدة الافتتاحية واحتساب الأرصدة الناتجة عن الحركات المرتبطة بهم.
- تقارير حسب اليوم أو الشهر أو كامل الفترة، مع اختيار المصنع أو المحل أو الحسابين.
- تصدير نسخة احتياطية JSON واستعادتها.

## بناء APK من GitHub
1. ارفع **محتويات هذا المجلد** إلى جذر المستودع في الفرع `main` (يجب أن يكون `app/` و`build.gradle.kts` في جذر المستودع).
2. افتح تبويب **Actions** في GitHub.
3. شغّل سير العمل **Build Android APK** أو انتظر تشغيله تلقائياً بعد الرفع.
4. بعد نجاحه افتح نتيجة التشغيل ونزّل Artifact باسم `AlBashaAccounting-debug-apk`.
5. فك ضغط الملف الناتج وثبّت `app-debug.apk` على هاتف Android.

## تنبيهات مهمة
- ملف APK غير مضمّن في هذه الحزمة؛ يجب بناؤه عبر GitHub Actions أو Android Studio.
- هذه نسخة تشغيلية أولية مطوّرة وليست برنامجاً محاسبياً مدققاً. التقارير تقديرية ولا تتضمن بعد دفتر أستاذ مزدوج القيد، أو إهلاك الأصول، أو الضرائب، أو تسويات المخزون المحاسبية.
- بيانات التطبيق محفوظة محلياً في مساحة التطبيق/المتصفح على الهاتف. لا توجد مزامنة سحابية أو تعدد مستخدمين. لا تحذف التطبيق أو بياناته قبل تصدير نسخة احتياطية.
- ربط مبيعات أو مشتريات بعميل/مورد يجعلها تؤثر في رصيده. أدخل التحصيلات وسداد الموردين كحركات مستقلة.
- تكلفة دفعة الإنتاج تُسجل في سجل التشغيلات ولا تُرحّل تلقائياً كمصروف مالي؛ تجنب تسجيل نفس التكلفة مرتين.
- اختبر التطبيق ببيانات تجريبية وراجع الحسابات مع محاسب قبل استخدامه كسجل رسمي.
